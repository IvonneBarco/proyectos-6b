SistemasEDUPRO

Sistema de Gestión Educativa

📋 Descripción

Aplicación web desarrollada con Angular que permite gestionar cursos, estudiantes e inscripciones de manera sencilla. Los usuarios podrán registrarse, consultar cursos disponibles, inscribirse y administrar la información académica, utilizando un backend para manejar los datos y una base de datos para almacenarlos.

⚙️ Funcionalidades
  • 👤 Registro e inicio de sesión de usuarios
  • 📚 Consulta de cursos disponibles
  • ✅ Inscripción a cursos
  • 🗂️ Administración de información académica
🛠️ Tecnologías
Angular Backend API Base de Datos HTML / CSS TypeScript
